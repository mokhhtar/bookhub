Book mind reader

Think of a book. Answer honestly — "don't know" is a real answer.

Loading…

The whole game runs in this page, from a table of books built from Open Library and Wikidata. It knows about 5,000 of the most-read books, so it will not know every book, and when it does not it says so rather than guessing. Playing sends nothing. If it fails and you choose to tell it which book you meant, that one answer — the book, and what you answered about it — is shared so the game can learn. Nothing else, and only if you tap it.
