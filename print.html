--- layout: default title: "Print or Save as PDF" description: "The whole book on one page, typeset for printing — save it as a PDF from your browser." permalink: /print/ sitemap: false --- {%- comment -%} Project Gutenberg publishes no PDF, and making one on our side would mean carrying a rendering engine on a 512MB box with no persistent disk. So we don't make one: this page is the book as a single, properly typeset document, and the BROWSER's print engine makes the PDF — the best typesetter available, already installed, free. Same noindex reasoning as /reader/, only more so: this mirrors the entire Gutenberg text on one URL. {%- endcomment -%}
Back {%- comment -%} Called "Save as PDF" and not "Download PDF" because it opens the print dialog — the file appears only once the reader chooses the PDF destination. Promising a download would be a small lie discovered one second later. {%- endcomment -%} Opens your browser’s print dialog — choose Save as PDF as the destination. {%- comment -%} The page number and the page's own URL that browsers stamp into every printed sheet are the browser's, not ours: no CSS removes them, and the one trick that works in Chrome (@page margin 0) buys it by printing the text against the paper edge on all 785 pages. So the checkbox gets named instead. What we CAN control is what those two lines SAY, and both were embarrassing — see the script below. {%- endcomment -%} For a clean file, open More settings there and untick Headers and footers — that removes the page numbers and the web address browsers print at the edge of every page.
